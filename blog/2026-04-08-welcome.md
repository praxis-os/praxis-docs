# Welcome to praxis

We are excited to launch the documentation site for **praxis** -- a production-grade Go library for orchestrating LLM agents with enterprise guardrails built in.

{/* truncate */}

## What is praxis?

praxis is an invocation kernel: the component that owns a single agent call from request to terminal state, with security, cost, and observability contracts enforced by construction. It gives you:

- A typed state machine with 11 states and allow-listed transitions
- A provider-agnostic `llm.Provider` interface (Anthropic shipped, OpenAI coming in v0.3.0)
- Four-phase policy hooks with filter chains at every trust boundary
- Four-dimensional budget enforcement (wall-clock, tokens, tool calls, cost)
- Mandatory OpenTelemetry observability
- Optional Ed25519 JWT identity signing per tool call

## Current Status

praxis is at **v0.1.0** -- the first public release with synchronous `Invoke`, the full state machine, the Anthropic provider, typed errors, and null defaults for all optional components.

The API is unstable during v0.x. We are working toward v1.0.0 with a formal interface freeze.
